# Agent Note: 将八份退役文档的有效合同收敛到 owning notes

Status: implemented — #151 所有者明确要求删除八份 docs 文档；本轮未提交工作落实入口迁移

## Problem

前次整理保留了四份历史/运行文档，加上已跟踪的四份合同，仍形成八个 docs 入口。只有薄指针而删除原文会丢失门槛与操作约束；保留重复副本又使后续维护不明确。

## Decision

按所有者本次指示退役这八个 docs 路径。有效合同归到同主题 owning note，历史原稿做完整本地备份；事件合同完整迁移，其他合同保留有效条款，研究提案仍为 proposed。
更新 AGENTS、接口、脚本、套餐 source 元数据和 notes 引用；notes 中只保留一个维护入口，当前状态仍由 GitHub 和实际证据负责。
本次对 [此前职责分工](2026-10-24-agent-guidance-and-decision-notes.md) 作局部调整：指定合同可与理由共址，不再要求这八份原文留在 docs。根接口与部署文档继续独立维护。

## Alternatives considered

- 删除原文但不处理指针或只留下空壳：不采用，会静默丢失运行合同。
- 把所有历史报告、机器输出和备份都迁到 notes：不采用，过程材料仍留本地。
- 原文和 notes 同时维护相同参数：不采用，增加双重真源。

## Consequences

owning note 既写理由也承载本主题合同，修改行为时同步该篇；文件存在不代表提案实现或生产启用。安全审批、真实验证门槛和测试数据隔离不改变。
本轮退役不能代替 commit/PR/CI/独立复核或生产许可；恢复依赖已验证本地备份。
