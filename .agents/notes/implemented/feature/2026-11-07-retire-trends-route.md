# Agent Note: 退役趋势追踪的旧页面地址

Status: implemented — 仅保留当日精选的现行入口，不维护旧页面兼容层

## Problem

[入口收敛](2026-11-07-picks-materials-entry.md)曾保留 `/trends` 跳转。所有者随后明确不需要兼容旧链接；站内入口已经统一，继续维护旧页面及参数转换只会增加一套无必要的路由合同。

## Decision

- 删除 `/trends` 前台页面及其兼容重定向、旧参数转换函数，访问旧地址由框架返回404，不新增退役提示页。
- 现行入口保持 `/today-picks`，话题线索和高频热词分别使用 `view=topics`、`view=keywords`。
- 站内链接使用现行入口；后端 `/api/v1/trends/*` 数据接口与被新视图复用的组件仍服务现行功能，不属于退役页面。
- 本决定替代入口收敛笔记中保留旧地址的单项决定，其余数据、筛选、分页与视图边界继续有效。

## Alternatives considered

- 继续保留兼容跳转：所有者认为没有必要，因此退役。

## Consequences

历史收藏或外部旧链接将得到404。这是本次明确接受的路由变化，不代表已部署上线。删除前已在本地`.vidt/`备份精确文件，可按路径恢复；不涉及数据库或依赖。

## Verification

`retired-trends-route.test.ts` 防止重新注册旧页面或配置重定向；当前视图、导航与数据API另有回归。实际HTTP状态通过本地Next验证，不能替代生产部署后的验证。
