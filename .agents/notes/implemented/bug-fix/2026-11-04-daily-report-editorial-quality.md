# 日报的事实标题、素材身份与内容校验

Status: implemented — 内容校验实现见 #230；本篇维护生成合同，不声明真实模型效果或线上历史日报验收

## Problem

标题被要求强行降低与原文的重合度，并从固定观点句式里选，容易将未填充的字母模板当成成稿。素材编号仅用于模型输入，直接出现在理由中时读者无法定位。原匹配器会保留模型声称的原文标题，甚至在显式编号无效时按其它字段重新匹配；输入整体截断后仍允许匹配完整候选池，也无法证明模型看过对应素材。

## Decision

- 标题先保证具体、准确和可回查，可直接采用忠实原题；写作价值来自新变化、受影响对象和具体切入点，不强求冲突、字面差异、固定句式或凑足数量。
- 输入预算按完整素材单元装入；匹配使用同一份实际可见素材池。显式编号无效则拒绝该项，旧格式缺编号才允许唯一标题或URL匹配；不凭不唯一的子串猜归属。同一素材只保留一次，最多9条。
- URL、原文标题、content_id与评分由匹配到的素材注入。原文身份冲突、可识别的模板残留或无映射内部编号触发warning，并回到该素材的标题和摘要，降为速览，撤掉相应的角度/生命周期判断。不会通过只删几个字符来保留不完整推论。
- 概览、主句、趋势、平台建议也检查同类问题。原题中真实存在的外部issue编号可保留；正常产品名X、C#版本不按占位符处理。模型无有效选题时仅从本次已提供素材构造保守摘要。
- 离线回退同样保留原题，source_idx始终是输入位置，不能因重新按分数排序就变成另一篇素材。

## Alternatives considered

只在前端替换字母或删除编号：不能恢复事实与论证，也会留下语义断裂，因此不采用。只修提示词：模型仍可能返回非法内容，不能代替确定性校验。对所有句子作关键词重合或数值匹配以宣称事实核查：相关性不等于推论成立，容易误伤正常表达，也不能作为事实正确证明。

## Consequences

保守回退可能减少精讲篇数、丢弃部分模型判断，运营日志会明确记录原因。素材摘要可来自上游AI分析，仍不是独立核实的一手事实。校验只覆盖确定性的格式、引用与身份边界；无法自动证明任意事实、因果、利润比较、认证或IPO表述正确。这些仍须对照原文并通过真实模型样本评估，不因本地测试通过就声称已解决所有内容质量问题。

历史已生成日报不在这次代码修改中重写；生产重新生成、群推送、真实Provider费用和部署各自需要对应授权。日报公私隔离及版本身份继续由[归属与生成合同](2026-10-22-daily-report-ownership-and-generation.md)维护。
