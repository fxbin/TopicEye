# Agent Note: 创作保留快速与探索两条路径，效果另行验证

Status: implemented — 基线 738ac61 存在快速生成和 explore/focus/converge 路径；#151 补录理由

## Problem

一次性生成适合已有明确目标的用户，强制多轮追问会增加负担；目标不清时只填模板又可能压掉值得探索的角度。旧创作圆桌讨论了多种评估比例，但模拟发言和自检分数并不是用户效果。

## Decision

[快速生成](../../../../backend/app/services/creation.py) 与 [探索服务](../../../../backend/app/services/creation_explore.py) 并存，按意图提供不同深度；探索先挑战假设、聚焦再收敛，最终仍由创作者判断方案。
所有阶段共享清晰的内容身份与归属，失败时保留用户草稿；相关最近修复见 5d1ab45。AI 自评只作为辅助信息，规则通过也不能宣称创作质量或真实需求已验证。

## Alternatives considered

- 让所有用户都经过完整多轮流程：不采用，忽略明确目标场景。
- 以角色模仿、自评通过或讨论中的固定采用率/回忆比例证明有效：不采用，缺少独立行为证据。
- 从早期 PRD 自动恢复批量搬运、互动自动化或不具备输入的爆文承诺：不采用，扩展须分别核实范围与证据。

## Consequences

现有代码形态不等于真实使用效果。后续比较采用、有效修改、完成和复用等行为，并记录失败/退出，评估标准与目标和测试批次绑定，不能把旧圆桌数值直接升为门禁。
本次未改 prompt 或创作链路；早期 PRD 的功能排期、SQLite 路线和模拟讨论的归因均不作为当前合同。
