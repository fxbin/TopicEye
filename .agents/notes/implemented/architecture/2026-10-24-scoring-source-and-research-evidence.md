# Agent Note: 统一评分口径与证明推荐效果是两件事

Status: implemented — 既有口径门禁见 fc26985；#151 整理 AIHOT/Easel 研究的复用边界

## Problem

旧 AIHOT 对标、Easel 调研和早期 PRD 包含隐含权重猜测、榜单样本统计与大量候选功能。公开精选池不等于全量候选，角色讨论的 adopt/trial 也不是已完成的产品验证。

## Decision

- 内部评分权重、门槛与术语从 [scoring_caliber](../../../../backend/app/core/scoring_caliber.py) 取用，前端镜像通过 [检查脚本](../../../../backend/scripts/check_scoring_mirror.py) 对账；不把外部产品的隐含规则抄成事实。
- 候选资格、事件展示代表、价值判断与页面容量分别解释。某条未展示不自动等于负样本；按批次分位数入选也不等于经过校准的正确概率。
- 历史有限 feed、合成回归与模拟圆桌只提供研究线索。真实效果需独立标注、分离校准/留出，并比较实际调用链；具体离线合同沿用 [SelectBench](../verification/2026-10-24-selectbench-contract.md)，事件试点沿用 [既有验证 note](../../proposed/verification/2026-10-24-event-normalization-real-evidence.md)。

## Alternatives considered

- 从公开分数反推竞争产品的隐藏轴、精确权重或人工编辑参与度：不采用，证据不可识别。
- 把多个榜同时出现直接当事实核验，把 LLM 爆文潜力分当实测传播率：不采用，指标来源不同。
- 据旧 PRD 恢复“低粉爆文”承诺：不采用。历史退场见 `32194b4`；重开需先证明粉丝、阅读与互动等输入的覆盖及口径，不能由主观分补足缺失事实。

## Consequences

口径检查保护内部一致性，不保证模型判断质量或用户采用。旧研究提出的行为锚点、显式画像、支柱配额、供给缺口和第三方备源属于各自待验证假设；本次整理没有批准其上线、固定探索比例或把外部 API 纳入 SLA。
重开应绑定真实来源、分布变化、误杀/降级语义和可回收条件，而不是沿用旧研究的共识票数、日期或测量结果。


## 算法解释与真实精选同源（#225）

解释页复用当日精选的完整候选、可读依据、个人忽略、静音规则、事件展示代表和统一评分；解释样本上限只在评分后截取，不能改变分位数或正式入选名单。时间窗口优先原文发布时间，缺失时回退抓取时间；诊断计数不能先于真实候选判空。

页面区分原始维度、权重贡献、基础分、来源加分与软降权，并标明本地降级待复核及未入选原因。硬规则被排除的数量与软降权分开表达；载入后的额外排除数量不冒充数据库查询前的完整排除量。正式入选后的个性化展示顺序仍由精选页处理，本页解释个性化排序之前的基础评分，不能承诺复现首屏每个位置。

解释缓存绑定用户和事件修订，另有有限有效期与显式失效。合成页面验收和隔离数据库回归证明数据契约及交互，不证明真实 Provider、模型质量或用户收益；本次没有调整评分权重或提示词意图。

## 按形态细分评分证据（#233）

实现工单为 [#233](https://github.com/fxbin/TopicEye/issues/233)，本节维护类型化标尺的运行合同。

- [content_types](../../../../backend/app/core/content_types.py) 是形态列表、别名和兼容归一化的共同入口；分类服务保持原有导出和未知值截断透传行为。主题 `category` 不用于选择评分标尺。
- [content_type_rubrics](../../../../backend/app/core/content_type_rubrics.py) 维护十种形态和通用标尺的中英证据要求、四档质量/使用价值、信息密度、创作者价值及反例。档位取自 `scoring_caliber.ANCHOR_BANDS`；版本标记随实际系统消息进入现有响应缓存身份。标尺字段优先于用户模板的通用描述，不产生类型固定加分，不改权重、风险和精选门槛。
- 完整分析只附当前类型的一段。Lite预筛消费同源段落；证据不足或标签与正文冲突时要求低置信并升级，不再以所有内容是否具有操作步骤判断价值。未知或缺失形态明确使用通用规则，不为缺分类额外调用模型、不猜主题映射、不反写分类。
- `论文`及其既有别名、或原有arXiv来源检测，进入论文专用流程并跳过Lite；`deep_read`按既有归一化合同保存。论文可以由实验或证明支持，预印本、名校/名企、只有摘要都不自动证明严谨。非arXiv论文的本地降级不宣称来自arXiv、不制造精读已核验结果。
- 标尺支持新闻的跟进判断、观点的解释判断、工具的采用判断，同时对教程复现、评测实测、项目运行材料提出相应证据要求。类型只改变需要何种证据，不把同类内容自动排到别类前面。系统提示词不回显不受信任的未知类型原文。
- Prompt目录登记完整双语规则快照供检查；不是每次请求发送所有规则。统计仍按scene归属，不从当前目录或规则版本倒推历史请求。旧分析不自动重评，历史缓存不删除；实际新请求使用带标尺的消息身份。

放弃“按类型换权重/固定加分”与“新闻无步骤必低分/个人经历必低分”的做法：前者需独立校准，后者混淆用途与内容形态。仍保留本地降级估分与Lite简化分数的既有语义；它们不因此成为完整Pro维度或真实质量证明。

回归见 [test_content_type_rubrics](../../../../backend/tests/test_content_type_rubrics.py)，验证类型、语言、预筛/完整调用与论文保存合同；mock不证明模型真实理解或跨类型分数已校准。来源名称/发布时间等既有元数据仍未额外注入title/body模板，时效与权威判断仅能依赖输入片段，不能宣称已作真实校准。真实Provider与独立人工留出集另行验收，沿用SelectBench证据边界。回退通过恢复本批提示词、路由及规则代码，不批量回写历史数据。
