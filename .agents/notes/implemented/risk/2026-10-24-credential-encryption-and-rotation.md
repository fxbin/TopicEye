# Agent Note: 加密落库不代替凭据吊销与主密钥恢复

Status: implemented — 加密实现见 e7c2267；#151 修正文档，未执行生产轮换或明文迁移

## Problem

旧集成审查与密钥指南记录过凭据暴露风险。把新值加密入库不能撤销旧 Key；直接更换主密钥，也不能让已有密文自动变成可解密的新格式。

## Decision

用成熟的 Fernet 实现落库加密，接口只暴露配置状态；供应商 Key 吊销/轮换与加密主密钥迁移分开验收。当前入口与操作合同统一维护在本篇下方，原 docs 路径退役。
迁移脚本只处理非 enc:v1 值，既有密文会跳过；它不提供主密钥重加密，也不会证明旧 Key 已失效或所有密文都可解密。

## Alternatives considered

- 加密或删除历史文档后就认为凭据事件关闭：不采用，外部密钥有效性没有因此改变。
- 先换主密钥，再运行明文迁移脚本：不采用，旧密文仍由旧材料加密。
- 在文档、日志或临时 CSV 中导出明文，借此轮换：不采用，扩大敏感材料的留存面。

## Consequences

主密钥与备份需要独立保管；丢失旧材料且无可恢复凭据时，需重新配置。重加密必须有准确范围、旧/新材料、恢复演练和验证，不由本次文档整理授权。
历史疑似暴露的供应商 Key 是否已吊销需外部证据；本笔记不声称已完成。原始审查仅进本地受限备份，不将凭据原值纳入 notes 或新文档。

## 运行合同

### 当前实现

- [secret_store](../../../../backend/app/services/secret_store.py) 使用 Fernet，加密值为 `enc:v1:` 前缀。
- 加密材料优先取 `INTEGRATION_SECRET_KEY`；未配置时取 `APP_SECRET_KEY`，再回退本地默认材料。生产不允许默认材料；启动检查见 [main](../../../../backend/app/main.py)。这不是“生产仅接受 INTEGRATION_SECRET_KEY”。
- 写入入口加密、LLM 读取入口解密；[模型 API](../../../../backend/app/api/v1/llm_models.py) 的正常响应只返回 `api_key_set`。配置状态为 true 不证明外部 Key 有效。
- 非 `enc:v1:` 值仍可按兼容路径读取；既有密文必须由匹配的材料解密。丢失材料、换错材料或损坏密文不能靠前缀检测恢复。
- 共享 secret_store 也被 OAuth/用户集成使用，不能只清点模型表就替换主密钥。当前消费方须从代码引用确认。

### 供应商 Key 的轮换

疑似暴露的 Key 应在供应商侧确认吊销/失效，并重新配置替代值。落库加密、改文档或清理本地原稿都不撤销旧 Key。
具体外部轮换、实际调用和费用按当次授权执行；凭据在配置界面或受保护的部署渠道输入，不写进文档、日志、截图或普通导出。
部署所用主密钥与可恢复备份应独立保管。不得仅覆盖环境变量来完成主密钥轮换。

### 存量明文迁移

[迁移脚本](../../../../backend/scripts/migrate_llm_api_keys.py) 默认读取并扫描 `llm_models.api_key`，只有 `--apply` 写库。下列是获得该环境操作授权后的命令，文档整理不执行它们：

```bash
cd backend
./scripts/backup_db.sh
uv run --no-sync python scripts/migrate_llm_api_keys.py
# 核对准确环境、备份、扫描范围和主密钥后，获准执行：
uv run --no-sync python scripts/migrate_llm_api_keys.py --apply
uv run --no-sync python scripts/migrate_llm_api_keys.py
```

脚本按每 20 行提交一次，错误可能留下已提交的前批次；中断后先核实库中状态再决定续跑。回滚依赖与原主密钥匹配的数据库备份及已验证恢复路径。
`enc:v1:` 行被跳过，不会验证其能否解密。扫描显示 0 个明文不等于旧 Key 已吊销、密文全部有效或生产已验收。

### 主密钥更换

现有明文迁移脚本**不支持**已有密文的主密钥重加密，不能先换主密钥再运行该脚本。
实际更换需独立安排：清点所有共享消费者、保留旧材料和一致备份、明确写入窗口、设计由旧材料解密并用新材料加密的过程、在隔离环境验证恢复，再执行准确范围的变更。
不能把解密后的明文落成通用文件作为中转。没有经过验证的重加密与恢复过程时，保留现有主密钥。

本页只说明现有工具边界，不声称已经提供通用轮换工具、执行生产迁移或关闭历史凭据风险。
