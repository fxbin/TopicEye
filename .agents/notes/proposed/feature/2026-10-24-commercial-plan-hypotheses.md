# Agent Note: 套餐目录的历史商业假设

Status: proposed — #151 按所有者明确要求迁移既有入口；不改变运行或生产授权

## Problem

套餐 API 的 source 字段需要可维护来源；早期 PRD 的定价和功能清单只能作为历史假设，不能成为当前售卖承诺。

## Decision

本篇维护下列合同；修改对应行为时同步核对，参数与安全边界沿用迁移前原文。

## 商业模式初稿

### 免费版

```text
每日查看部分今日选题
基础摘要
基础推荐理由
少量收藏
```

### Pro 版：19-49 元/月

```text
查看全部今日选题
查看低粉爆文
AI 选题转化
小红书爆款浏览
收藏夹
每日 Brief
```

### Studio 版：99-199 元/月

```text
自定义信源
批量选题分析
竞品账号监控
导出选题库
团队成员
策略配置
```

### 企业版

```text
专属行业信源库
私有部署
团队协作
API 接入
企业微信/飞书推送
专属策略模型
```

---


## Alternatives considered

只删除文档而保留断链或省略合同：不采用，入口收敛不能丢失使用边界。

## Consequences

当前套餐名称、展示与限额以 [plan_catalog](../../../../backend/app/services/plan_catalog.py) 及 API 为准。下方数值与能力均为旧商业模式假设，未因迁移而开放或验证；原 PRD 全文已有本地备份。
