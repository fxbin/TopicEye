# Agent Note: 阅读推荐先验证下一步深读任务

Status: proposed — #151 保留旧阅读圆桌候选，未将方案登记为已实现或已验证

## Problem

划线数、想法数和进度可能帮助理解阅读兴趣，但高阅读活动不必然等于想读某本书；推荐列表也可能只是热门内容的另一种排列。

## Decision

保留“下一步深读什么”的最小候选：结合用户自己的阅读材料给出可解释的路径建议，并允许已读、想读、换方向和查看理由等反馈。
先确认候选书来源、材料可见性/使用授权、现有 [阅读材料服务](../../../../backend/app/services/weread_materials.py) 能力与效果度量，再决定 prompt 卡片、排序或 embedding。

## Alternatives considered

- 一开始构建完整知识图谱、embedding 重排与推荐看板：暂不采用，先验证是否解决实际任务。
- 固化“至少 30% 探索”或宣称“80% 评分逻辑可复用”：不采用旧讨论的未验证数字；书籍路径与内容选题评分的输入/目标并不天然相同。
- 把 AI 生成的角色圆桌当读者访谈或专家背书：不采用。

## Consequences

候选池、偏好时间漂移、探索比例、“换方向”改变什么和隐私边界仍待决定。采纳与后续深读是效果证据，点击不等于受益。
这是独立候选，不恢复旧路线图优先级；本次不新增抓取、推荐 API、模型调用或用户数据处理。
