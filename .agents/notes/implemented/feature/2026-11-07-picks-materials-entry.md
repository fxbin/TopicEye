# Agent Note: 精选、话题线索与热词共用一个入口

Status: implemented — 前台当日精选承载主选池与两种辅助观察视图

## Problem

当日精选已经支持话题分组与7天内容浏览；趋势追踪在同一内容库上再次提供原题索引和材料阅读，两处入口的用户任务明显重叠。已有快照尚不足以证明稳定跨日趋势，独立导航会放大其能力承诺。

## Decision

- `/today-picks` 默认进入精选内容；`view=topics` 为话题线索，`view=keywords` 为高频热词。前台导航仅保留当日精选入口；日报链接直接进入相应辅助视图。
- 精选沿用原入选门槛、评分、个性化、话题/列表、阅读及追加分页。话题线索覆盖公共收录，包含未入选文章；热词反映公共内容分析标签频率。三者不共用分母，不以标签频率冒充搜索热度。
- 精选展示方式明确列出列表与分组选项。当前已加载且筛选后的文章没有可展示话题时，回退评分列表、禁用分组选项并说明原因；不凭分类或标签补造话题。文章缺少对应话题资料时仍放在其他精选，追加页补齐资料后再进入真实组，避免分组模式漏文。
- URL 是视图和筛选的事实源。精选使用 `category`、`content_type`、`level`、`time_range`；辅助使用独立的 `days`（3/7/14/30，默认7）。切换保留各自参数，前进/后退同步控件与请求。
- 隐藏精选保留已加载条目、展开状态及筛选，停止其滚动自动加载；辅助只在选中时挂载。切换时隐藏旧范围数据，投影和请求身份一致后才展示；滚动按视图及范围记忆，内容ready后恢复，拒绝旧范围恢复回调。
- **已由[旧地址退役决定](2026-11-07-retire-trends-route.md)替代的历史决定：** `/trends` 当时保留为兼容入口，服务端归一到 `/today-picks?view=topics`；合法热词目标与窗口保留，未知或重复参数回落默认，目标固定为站内。它不再维护第二套前台页面。
- 材料的日期、缺口、计算口径、冻结成员及降级语义继续由[趋势与来源合同](../architecture/2026-10-24-trend-and-source-provenance.md)维护。历史收录数量读取对应日 `daily_counts`，现存/筛选可查看数量读取 `total`；`summary` 的现存成员统计不代替历史分母。

## Alternatives considered

- 只改页面名字、保留两个一级入口：不采用，不能消除重复任务。
- 为保持独立趋势页而补造走势、稳定话题身份或全网热度：不采用，现有证据不支持。
- 合并后删除快照与成员接口：不采用，材料回查与标签分布仍有独立价值。

界面采用“话题线索”命名，强调从收录内容发现可跟进的问题；展开后的文章仍称材料。该命名不改变数据范围、入选规则或URL。

## Consequences

用户在一处入口完成选文章和补查材料，辅助视图需要一次切换。只有未来能可靠提供跨日身份、可比覆盖、变化与新增材料时，再评估独立趋势入口；本次不重建后端、不迁移数据库，也不声称真实选题收益已提升。
