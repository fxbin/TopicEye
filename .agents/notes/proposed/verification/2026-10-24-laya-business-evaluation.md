# Agent Note: Laya 保持有退出条件的候选试验

Status: proposed — 保留 2026-09-28 设计建议；#151 未安装、调用或启用该依赖

## Problem

有限选项模型可能节约分类成本，但上游测速、输出格式稳定或高 confidence 均不能证明 TopicEye 的中文分类效果与净收益。

## Decision

原设计文档按所有者要求退役，本篇维护提案边界与以下设计摘要；2026-09-28 原稿完整保存在本地备份。
先独立试验，再考虑影子与辅助模式；原链路作为异常、弃权和字段不足时的回退。分类还要产出标签或新类别时，不能只替换部分字段就声称整次 LLM 调用被省掉。

## Alternatives considered

- 将格式正确、上游历史中文成绩或 T4 延迟当成本项目验收：不采用，数据、硬件与版本不一致。
- 直接替代生成、排序或自动事件归并：不采用，能力边界与误判代价不同。

## Consequences

下方数字是历史方案而非当前通过标准。正式试验须重新确认依赖/权重版本、实际许可与资源、中文业务集、冷暖延迟、校准和包含失败的净成本；新证据决定继续或退出。
整理文档不授权模型下载、外部调用、部署或生产启用。原文中的“可行”不提升为已实现或已验收。

## 设计摘要与验证计划

### 历史来源与能力边界

原设计固定上游代码为 `9d955671415fc19f069b9cc998928075c1f255ec`，包声明 `0.3.21`，来源为 [固定版本项目](https://github.com/NandhaKishorM/laya/tree/9d955671415fc19f069b9cc998928075c1f255ec)。这些不是当前最新版或已验证安装；重新执行前核对依赖、checkpoint/权重哈希、许可与资源。
首期候选是 [分类器](../../../../backend/app/services/classifier.py) 的 category/content_type 有限选项；只争取关键词快速路径之后的分类慢路径。独立推理进程避免每个 API worker 重复装载权重；原设计适配 `/v1/systemone` 与 `/health`，不是 Chat Completions 兼容假设。
摘要、标签生成、新类别发现、最终排序和事件自动归并不随首期替换。任一旧契约字段无合法来源时回退完整 LLM；confidence 不与旧分类器或事实置信度混用。

### 模式、审计与恢复

候选模式为 off/shadow/assist，默认关闭。shadow 仍运行原链路，只比较输出；assist 须按任务/语言校准后有限采纳。缺字段、非白名单选项、unknown、异常 JSON、非有限或不在 [0,1] 的置信度、未知版本、截断及 token 冲突均弃权/回退。
缓存绑定 owner、文本/候选集哈希、任务、问题、模型和策略版本，命中后仍校验当前策略；不得默认重复存私有正文。不在网络调用期间增长事务，影子任务需随应用停机回收。
在线回写保存原值与决策关联；回滚用行版本/当前值条件，不能覆盖后续人工改动。关闭模式只停止新采纳，不能恢复历史写入。若试验事件关系，单独标注与验收，先 shadow/pending，不借旧置信门槛自动合并。

### 待冻结的试验口径

先统计代表性流量的关键词命中、各 LLM 场景调用、费用和延迟。原建议不少于 1,000 条真实内容，按语言/来源/主题/形态分层；开发、校准、留出按事件与时间分开，人工裁决标签，旧 LLM 仅作基线。错误/超时不从分母删除，样本不足的层不自动接受。
对照完整现有链路、规则基线、Laya 全量和混合链路，报告每类指标、macro-F1、接受覆盖与置信区间、unknown/新类别/标签覆盖及下游变化。
历史建议门槛：接受样本精度的 95% 置信下界至少 95%；混合链路 macro-F1 降幅不超过 1 个百分点；覆盖原慢路径至少 30% 且满足全部字段；含部署、复核和回退的净分类成本至少降低 20%，采集 p95 不退化。它们需在正式试验前重新冻结，未证明达成。
故障恢复、off 等价和下游冻结回放分别验收；候选顺序交换、同义/否定、提示注入、空值与长输入做变形检查。首期不微调。
净收益分母是原分类 LLM 调用量，不是全部采集量；本地推理和影子调用不记为零成本。收益不足、标签仍需原调用或中文覆盖不足时结束试验。普通用户无需新菜单；有稳定评测后才考虑管理视图。
